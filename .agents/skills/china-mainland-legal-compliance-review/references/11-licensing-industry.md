# 11 — 许可证照与行业准入

## 目的

检查项目在中国大陆合法运营所需的证照、备案与登记。许可要求因行业差异很大；先识别适用项，再核实现有证据。

## 常见备案/证照（汇总矩阵）

| 事项 | 适用情形 | 说明 |
| --- | --- | --- |
| ICP 备案 | 在大陆境内托管的、面向大陆可访问的任何网站/App/服务 | 通过接入服务商（托管商）+ 工信部备案系统办理；网站须展示备案号。境外托管无需 ICP 备案，但会带来其他问题（访问、数据属地）。 |
| ICP 经营许可证（B25 信息服务业务） | 经营经营性信息服务（付费内容、广告驱动网站、特定平台） | 经营性 ICP 需要；取决于业务模式（电商平台、门户、资讯、会员服务）。 |
| 增值电信业务经营许可证（EDI 等） | 电商平台及其他增值电信服务 | 类别 B21–B25（如 EDI 在线数据处理与交易处理业务，适用于电商平台）。 |
| 网络文化经营许可证 | 网络文化内容（游戏、音乐、直播、演出） | 文化和旅游部门；覆盖网络音乐、网络表演、网络演出等。 |
| 网络出版服务许可证 | 网络出版（网文、漫画、有声书等） | 新闻出版部门。 |
| 互联网新闻信息服务许可证 | 新闻/信息服务、带编辑内容的信息流 | 网信办；限制谁可运营新闻网站（通常须为新闻单位或合作方）。 |
| 网信办备案（算法/深度合成/生成式 AI） | 算法推荐、深度合成、生成式 AI 服务 | 见参考 06、07；向网信办备案，有公开备案编号。 |
| 互联网药品信息服务资格证书 | 提供药品/医疗信息服务 | 药监局（NMPA）。 |
| 特殊行业广告前置审批 | 受监管行业的广告 | 见参考 09。 |
| 游戏版号（游戏出版审批 / ISBN） | 在中国大陆出版/运营游戏 | 须经国家新闻出版署批准（版号）后方可上线运营；无版号不得运营。 |
| 网络表演经纪（直播机构）/主播实名 | 直播机构与主播 | 文化和旅游部；主播实名、直播经纪机构备案。 |
| 等保备案 | 二级以上系统 | 见参考 04（公安机关）。 |
| 市场主体登记 | 运营主体须为大陆境内注册公司 | 多数证照要求主体为持有有效营业执照的大陆公司。 |
| 数据出境安全评估 / 标准合同备案 | 数据出境 | 见参考 03。 |

## 关键要求

1. **主体设立**：多数证照要求大陆注册公司（营业执照），经营范围涵盖相关活动。
2. **ICP 备案**是任何境内托管服务的基础，也是多数应用商店上架与其他证照的前提。备案号须展示（如网站页脚或 App"关于"页）。
3. **行业特定证照**取决于实际活动。先确认活动内容，再核对对应要求。
4. **游戏**：无版号运营游戏是常见且严重的违规；无版号时的预约登记也受限。
5. **应用商店要求**：大陆商店（应用宝、华为、小米、vivo、OPPO、App Store 中国区）要求 ICP 备案，并按类别要求额外证照与隐私合规文本（SDK 披露、隐私政策）。
6. **备案时限**：如算法/生成式 AI/深度合成备案须在服务上线 30 个工作日内完成（见参考 06、07）。

## 审查要点

- 是否有大陆运营主体（营业执照）？经营范围？
- 服务是否境内托管？是否展示 ICP 备案号？
- 业务模式是否属经营性 ICP（需许可证）？
- 是否属电商平台（EDI）或内容/文化/新闻/出版服务（专门证照）？
- 是否属游戏（版号）？
- 是否使用算法 / 生成式 AI / 深度合成（网信办备案）？
- 是否存在需前置审批的受监管行业广告（医疗/保健/金融）？

## 红旗

- **高**: 面向大陆用户提供服务却未 ICP 备案。
- **高**: 经营性信息服务无 ICP 经营许可证或 EDI。
- **高**: 游戏无版号即运营。
- **高**: 新闻内容服务无互联网新闻信息服务许可证。
- **中**: 未展示 ICP 备案号。
- **中**: 文化/直播服务无网络文化经营许可证。
- **中**: 药品/医疗信息无互联网药品信息服务资格证书。
- **中**: 算法/生成式 AI/深度合成服务未完成网信办备案。

## 评估说明

- 证照要求高度依赖具体业务模式；矩阵用于路由判断，最终认定需结合产品事实（且常需律师意见）。
- 不得虚构备案号或许可证；缺失记为发现项并注明适用要求。
